# URL Archaeology

> Excavate dead links and let resurrected 2012 websites judge your taste.

A web app that scans a folder of old bookmarks, fetches Wayback Machine snapshots, and turns each stale link into a dig site. You assign artifacts, restore pages, and compare your old self to your present.

## Features
- Import a CSV or JSON bookmark list and detect missing domains.
- Pull the closest available Wayback Machine snapshot for each dead link.
- Build a dig-site UI where restored pages become fossil artifacts.
- Export a taste-judgment report comparing old interests to current ones.

## Stack
- React
- Vite
- Wayback Machine API
- Tailwind CSS

## Getting started
```
npm install && npm run dev
```
